# Tostik Town

A top-down toastie shop game for the browser. Press every toastie by hand, serve the neighborhood and grow your tiny shop.

**[▶ Play now](https://eustoregamestudio.github.io/tostik-town/)**

This repository hosts the playable build. The game is available in English and Turkish.

Made by [EUSTORE Game Studio](https://github.com/eustoregamestudio).
